# LFG Arcade

Play in your browser: https://lightning-forge-games.github.io/lfg-arcade/

A collection of classic games by Lightning Forge Games. Chess, Draughts,
Connect 4, Backgammon, Yahtzee and Snooker, each playable against the computer,
in hot seat, or online against a friend by sharing an invite link.

This repository holds the compiled web build only. The Unity project source
lives elsewhere.

Built with Unity 6000.3.7f1 (URP) and Photon Fusion.
